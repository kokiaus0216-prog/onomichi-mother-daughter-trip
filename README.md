# かえでとゆかの母娘旅行 in尾道 🍁

## ログイン不要で旅程をみんなで編集する（Firebase）

- **[Firebase初期設定（あと2つ）](FIREBASE_SETUP.md)**：Firebase Authenticationで「匿名」を有効化し、[firestore.rules](firestore.rules) をFirebase Consoleへ公開する。
- GitHubの `firebase-config.js` は `onomichi-trip-2026` の設定に接続済み。
- 旅行しおりの「旅程」画面に **「✏️ 旅程を追加・編集する」** を表示。認証設定後はログイン操作なしで自動接続・自動同期。
- 「＋予定を追加」や各予定の「✎ 編集」から、日時・場所・交通・Googleマップの情報を変更可能。
- **URLを知っている人は誰でも編集・削除可能**。個人情報や秘密を新たに登録しないようにする。ルールは旅行の旅程1件だけを許可する。
- 写真・旅費・持ち物は今までどおり各端末で保存され、まだクラウド同期対象ではない。


## GitHub Pagesで公開する

1. リポジトリを作るか既存のリポジトリを開きます。
2. ZIP内の `index.html` と `assets/onomichi-hero.svg` を**そのままの構成**でリポジトリのルートにアップロードします。
3. GitHub `Settings → Pages → Build and deployment → Deploy from a branch` にし、`main` と `/(root)` を選択して保存します。
4. `https://＜ユーザー名＞.github.io/＜リポジトリ名＞/` で公開できます。

## 旅のしおりの表示方法

- 11月28日と29日の全行程を**上から下へ1本の時間軸**として表示します。中央に時刻、左右交互に行き先と写真追加カードが並びます。
- **赤い丸は予定に基づく現在の目安**です。位置情報は取得しません。
- 上部に**日本時間、次の予定までの残り時間、次の電車の発車までの残り時間、次の確認済みバスの発車までの残り時間**を表示。15秒ごとに時刻を更新します。
- **「現在位置を見る」**を押すと赤い丸までスクロールします。
- 予定が「頃」の場合、カウントダウンも目安です。実際の鉄道遅延・バス運行には対応しません。
- デモ用URL：`?preview=2026-11-28T13:30` と付けると、その日時で赤丸・残り時間を試せます。通常は実際の現在時刻になります。

## 旅程

- 28日（土）：ゆか09:14佐賀→09:50博多、かえでと合流。博多10:15→福山11:41（4号車6C・6D）、駅周辺散歩、福山12:12→尾道12:31。荷物を預けランチ、烏須井八幡神社へ参拝（往復交通未確定）、尾道駅で荷物回収、尾道駅前4番乗り場14:50→三成15:10のバス（尾道工業団地線・300円／人）、ホテル15:15頃。神社の参拝と駅の荷物回収が14:50発に間に合うか、現地で接続確認が必要。16:55頃ホテル発→三成17:15→尾道駅前17:38（休日公式時刻表掲載）→徒歩約18〜25分→**18:00 HOK STAND予約済み**（尾道市久保1-2-24、到着は予約直前のため要注意）。夕食後20:35頃徒歩→尾道駅前21:08→三成21:23（早ければ20:05発もあり）、ホテル21:26頃。徒歩所要時間は推定なのでGoogleマップで確認。
- 29日（日）：08:30尾道浪漫珈琲三成店で朝食。朝食後にホテルへ戻って荷物を受け取り、**09:28ホテル出発→三成バス停まで徒歩2分（120m）→09:30三成発→09:36新尾道駅着**。尾道・三成線（尾道駅前行き）／7駅・所要6分／1人190円。11/29（日）の利用便として本人が画像で確認し指定した時刻を採用。新尾道で荷物を預ける→市街地でエタニティ、Rhinocéros、カルフ→長江周辺から新尾道（午後のバス便は未確定）。こだま953号15:28→博多17:51（4号車5C・5D）。ゆかのみ特急みどり博多18:11→佐賀18:56（6号車3D）。
- 福山のMonoiku（モノイク）は予定から完全に除外しました。
- 公共交通と徒歩のみ。レンタカーなし。電車とバスの時刻は出発前に再確認してください。

## 写真・費用など

- 各場所の「＋写真を追加」「カメラで撮る」から、写真を端末内のIndexedDBに保存します。
- アルバム表示、コメント追加、写真入りHTMLアルバム書き出し、印刷/PDF出力。
- 旅行費用と支払者（かえで／ゆか）、割り勘精算、持ち物チェック、メモ、JSONバックアップ／取り込み。
- **写真はブラウザごとに保存され、別端末と自動同期されません。** iPhoneのSafariデータを削除すると消える可能性があるため、適宜バックアップしてください。
- アルバムHTMLやバックアップJSONには写真等が含まれるので、**公開GitHubリポジトリにアップロードしないでください。**

## 利用について

サイトは静的HTMLとオリジナルイラストで構成され、サーバー設定不要。Google Fontsに接続することがあります。Googleマップは別タブで開きます。鉄道・バスのリアルタイム運行情報やGPS位置検知はありません。
