# 初！母娘の尾道旅行 🌷

かえで＆ゆかの2026年11月28日（土）〜29日（日）の旅行しおり。GitHub Pagesでそのまま使えます。

## GitHub Pagesで公開する

1. リポジトリを作るか既存のリポジトリを開きます。
2. ZIP内の `index.html` と `assets/onomichi-hero.svg` を**そのままの構成**でリポジトリのルートにアップロードします。
3. GitHub `Settings → Pages → Build and deployment → Deploy from a branch` にし、`main` と `/(root)` を選択して保存します。
4. `https://＜ユーザー名＞.github.io/＜リポジトリ名＞/` で公開できます。

## 旅のしおりの表示方法

- 11月28日と29日の全行程を**上から下へ1本の時間軸**として表示します。中央に時刻、左右交互に行き先と写真追加カードが並びます。
- **赤い丸は予定に基づく現在の目安**です。位置情報は取得しません。
- 上部に**日本時間、次の予定までの残り時間、次の電車の発車までの残り時間、次の確認済みバスの発車までの残り時間**を表示。15秒ごとに時刻を更新します。
- **「現在位置を見る」**を押すと赤い丸までスクロールします。
- 予定が「頃」の場合、カウントダウンも目安です。実際の鉄道遅延・バス運行には対応しません。
- デモ用URL：`?preview=2026-11-28T13:30` と付けると、その日時で赤丸・残り時間を試せます。通常は実際の現在時刻になります。

## 写真・費用など

- 各場所の「＋写真を追加」「カメラで撮る」から、写真を端末内のIndexedDBに保存します。
- アルバム表示、コメント追加、写真入りHTMLアルバム書き出し、印刷/PDF出力。
- 旅行費用と支払者（かえで／ゆか）、割り勘精算、持ち物チェック、メモ、JSONバックアップ／取り込み。
- **写真はブラウザごとに保存され、別端末と自動同期されません。** iPhoneのSafariデータを削除すると消える可能性があるため、適宜バックアップしてください。
- アルバムHTMLやバックアップJSONには写真等が含まれるので、**公開GitHubリポジトリにアップロードしないでください。**

## 利用について

サイトは静的HTMLとオリジナルイラストで構成され、サーバー設定不要。Google Fontsに接続することがあります。Googleマップは別タブで開きます。鉄道・バスのリアルタイム運行情報やGPS位置検知はありません。
